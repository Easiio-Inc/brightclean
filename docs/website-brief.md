# Website Brief — 亮净到家

## The seven Class 2 principles
1. **Target customer:** Busy Shanghai residents, families, renters moving out, and professionals with an urgent cleaning need.
2. **Customer problem:** They need the home cleaned quickly and do not want uncertainty about arrival time, price, or result.
3. **Core offer:** Professional cleaners arrive at the customer’s home with supplies; same-day slots are available.
4. **Outcome:** A clean, guest-ready home today, without sacrificing the customer’s time.
5. **Differentiation:** “Today means today,” phone-first booking, transparent hourly pricing, and a redo guarantee.
6. **Proof:** Completed-order count, rating, response time, on-time rate, process guarantees, and verified reviews. Demo values must be replaced with real data before launch.
7. **Primary CTA:** Call now to confirm today’s available time.

## Launch scope
A responsive static HTML one-page demonstration. It includes hero, time promise, scenarios, pricing, process, numeric proof, reviews, service area, FAQ, and phone-first CTA.

## Future WordPress path
Move the approved design into WordPress when the owner needs to update service pages, publish local SEO articles, manage promotions, or connect booking/CRM plugins. Build on staging and do not overwrite the current production homepage.
