# Design System

## Brand Direction
Fast, trustworthy, warm, local, and operationally clear—not luxury for luxury’s sake.

## Color Palette
- Deep teal `#123d3a`: trust, navigation, operational sections
- Burnt orange `#c75b32`: urgency and primary action
- Warm cream `#f5f0e7`: calm domestic environment
- Paper `#fffdf9`: main surface
- Ink `#17211f`: high-contrast copy
- Muted `#66706d`: supporting copy

## Typography
Chinese-first system stack: PingFang SC, Microsoft YaHei, Inter, system UI. Large compressed display headings, readable 16px body copy.

## Layout and Components
1180px desktop shell; strong first viewport; orange CTA; editorial image; numeric proof strip; three-column service cards; clear process; testimonials; FAQ; fixed mobile booking bar.

## Responsive and Accessibility
Single-column mobile layout, 44px-class tap targets, semantic landmarks, skip link, visible headings, descriptive alt text, reduced-motion support, high-contrast CTAs, phone links that work without JavaScript.
